# 水陸小高手｜生字語詞預習站

這是一個給國小四年級使用的單頁形成性評量網頁，內容取自教育百科「第一課：水陸小高手」的五個語詞：游泳、滑行、遨遊、陀螺、轉身。

## 直接試玩

用瀏覽器開啟 `index.html`，輸入任意班級座號代碼，例如 `401-08`。網頁包含：

- 5 題看圖選語詞
- 5 題認字找語詞
- 每題答對／答錯與詞義提示
- 完成後顯示總分、答對題數、答錯題數與逐題明細

若尚未設定 Apps Script，成果會先保存在使用裝置的瀏覽器 `localStorage`，不會自動送出。

## 連接 Google Apps Script

1. 建立一份 Google 試算表，選擇「擴充功能 → Apps Script」。
2. 將 `apps-script/Code.gs` 的內容貼入 Apps Script 編輯器並儲存。
3. 選擇「部署 → 新增部署」，類型選「網頁應用程式」。
4. 「執行身分」選自己；「誰可以存取」選「任何人」。
5. 複製部署完成後的 Web App URL。
6. 打開 `index.html`，找到 `const APP_SCRIPT_URL = "";`，把 URL 貼在雙引號中。

Apps Script 會在試算表建立「評量紀錄」工作表，欄位包含班級座號代碼、總分、答對／答錯題數、時間與每題明細。

## 注意

- 若修改 Apps Script 程式，請重新部署新版本。
- 網頁只要求班級座號代碼，不收集學生姓名。
- 這是預習型評量，分數每題 10 分，共 100 分；答錯會立即顯示正確語詞與提示。
