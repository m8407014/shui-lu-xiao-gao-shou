# 水陸小高手｜生字語詞預習站

這是一個給國小四年級使用的單頁形成性評量網頁，內容取自教育百科「第一課：水陸小高手」。評量分成 15 個生字複習，以及 5 個搭配插圖的動詞語詞：游泳、滑行、遨遊、轉身、煩惱。

## 直接試玩

用瀏覽器開啟 `index.html`，輸入任意班級座號代碼，例如 `401-08`。網頁包含：

- 15 題生字複習：注音選國字、國字選注音、看字選意思
- 5 題語詞看圖：用插圖理解游泳、滑行、遨遊、轉身、煩惱
- 每題答對／答錯與詞義提示
- 答對鼓勵音效、鼓勵文字與彩紙特效，可關閉音效
- 5 分鐘倒數計時，最後 30 秒會變色提醒
- 完成後顯示總分、答對題數、答錯題數與逐題明細

若尚未設定 Apps Script，成果會先保存在使用裝置的瀏覽器 `localStorage`，不會自動送出。

## 連接 Google Apps Script

1. 開啟 Google Apps Script，建立「新專案」。
2. 將 `apps-script/Code.gs` 的內容完整貼入編輯器並儲存。
3. 選擇「部署 → 新增部署」，類型選「網頁應用程式」。
4. 「執行身分」選自己；「誰可以存取」選「任何人」。
5. 複製部署完成後的 Web App URL。
6. 第一次用瀏覽器開啟 Web App URL，完成 Google 授權；程式會自動建立「水陸小高手｜學生評量紀錄」試算表。
7. 將 Web App URL 貼到 `app-config.js` 的 `window.APP_SCRIPT_URL` 雙引號中，再部署 `index.html`、`app-config.js`、`assets/`。

Apps Script 會自動建立試算表與「評量紀錄」工作表，欄位包含班級座號代碼、總分、答對／答錯題數、時間與每題明細。直接開啟 Web App URL 會回傳試算表網址。

## 注意

- 若修改 Apps Script 程式，請重新部署新版本。
- 網頁只要求班級座號代碼，不收集學生姓名。
- 這是預習型評量，共 20 題，依答對比例換算 100 分；答錯會立即顯示正確答案與提示。
